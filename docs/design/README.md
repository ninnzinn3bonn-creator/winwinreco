# GIJIRO mobile design package

This directory is the source of truth for the 2026 mobile-first UI refresh.

- `selected-mobile-direction.png`: approved 390 x 844 visual direction.
- `SOURCE_POLICY.md`: source, license, and dependency decisions.
- `APPLE_MOBILE_PRINCIPLES.md`: project-owned interpretation of the relevant HIG principles.
- `GIJIRO_DESIGN_SYSTEM.md`: tokens, components, responsive behavior, and screen contracts.

The reference image establishes visual hierarchy and interaction placement. Existing GIJIRO behavior, IDs, data flows, and security boundaries remain authoritative when the mockup omits a state.
