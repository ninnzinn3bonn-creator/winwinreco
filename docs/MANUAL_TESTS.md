# 手動回帰テスト手順

## モバイルUI回帰 (390 x 844)

共通トークン、固定ヘッダー、会議ドック、または画面構成を変更した場合は、
以下を先に確認する。

1. Welcome: 主要3導線が横スクロールなしで表示される。
2. Setup: 表示名・プロフィール・ルームIDの順序が維持され、下部CTAが常に操作できる。
3. Meeting: Live / 重要 / AI が切り替わり、現在発言とログが下部ドックに隠れない。
4. Meeting: マイク、メモ、重要、設定、終了が既存ハンドラへ接続されている。
5. Summary: 3タブが切り替わり、ログ、議事録、AIエディタが横にはみ出さない。
6. Admin / Progress / Reset / Verify / Terms / Privacy: 320px幅でも横スクロールしない。
7. キーボード操作でフォーカスリングが見え、セグメントは左右矢印でも移動できる。
8. OSの「視差効果を減らす」を有効にしたとき、必須操作がアニメーションに依存しない。

自動画像回帰は `npm run test:visual` で Welcome / Setup / Meeting /
Summary の4状態を検証する。

このファイルは自動テストで再現しにくい「エディタの経時動作」を手動で確認するためのチェックリストです。
B1〜B6 の修正 (エディタ自動上書きバグ対策) を確認することが主目的です。

---

## 前提

- アプリを起動 (`node src/backend/server.js`)
- ブラウザの DevTools → Network タブを開いておく (シナリオ 5 で使用)
- 会議を作成して終了し、**サマリー画面**を開いた状態から各シナリオを実施する

---

## シナリオ 1: 議事録を編集しても 6 秒で上書きされない

1. 「議事録」タブを開く。
2. 議事録エディタに任意のテキストを追記する (例: `--- 手動追記 ---`)。
3. そのまま **6 秒以上** 待機する。
4. **期待**: 追記したテキストが保持されたままになっている。
5. **失敗パターン**: テキストが消えてサーバーの値に戻る。

---

## シナリオ 2: 要約を編集しても 6 秒で上書きされない

1. 「AI整理」タブ → 要約を表示する (「要約を生成/表示」ボタンを押す)。
2. 要約エディタに任意のテキストを追記する。
3. **6 秒以上** 待機する。
4. **期待**: 追記が保持されたままになっている。

---

## シナリオ 3: カスタムプロンプトを編集しても上書きされない

1. 「AI整理」タブ → カスタムプロンプト欄に文字を入力する (例: `箇条書きで要約してください`)。
2. 「要約を生成」ボタンを押して結果を更新する。
3. **期待**: カスタムプロンプト欄の内容が保持されたままになっている。
4. さらに **6 秒以上** 待機して再確認する。

---

## シナリオ 4: 30 秒以上放置するとサーバー値で再同期される

1. シナリオ 1 〜 3 のいずれかの編集を行う。
2. **30 秒以上** 何もせず待機する。
3. DevTools → Application → Local Storage でタイムスタンプを直接クリアするか、
   コンソールで `AppState.state.editorDirty.minutes = 0` を実行して dirty を手動リセットする。
4. 次の `/insights` ポーリングが走るタイミングで再同期が起きる。
5. **期待**: サーバーの最新値でエディタが更新される (30 秒保護は切れる)。

> **Note**: 実装では 30 秒 (`withinMs = 30_000`) を dirty 保護の期限としている。

---

## シナリオ 5: 解析完了後に insights ポーリングが自動停止する

1. 要約の生成を実行する (processing 状態に入る)。
2. DevTools → Network タブで `/insights` のリクエストをフィルタリングして監視する。
3. 生成が完了 (status: ready) したあと、**Network タブを 10 秒観察** する。
4. **期待**: 生成完了後は `/insights` へのリクエストが止まる。
5. **失敗パターン**: 5 秒ごとに `/insights` が呼ばれ続ける。

> 新しい解析を開始すると polling が再開されることも確認すること。

---

## 合否判定

| シナリオ | 期待通りだったか | 備考 |
|---------|--------------|------|
| 1 — 議事録編集 6 秒待機 → 保持 | ☐ 合 / ☐ 否 | |
| 2 — 要約編集 6 秒待機 → 保持 | ☐ 合 / ☐ 否 | |
| 3 — カスタムプロンプト → 保持 | ☐ 合 / ☐ 否 | |
| 4 — 30 秒放置 → 再同期 | ☐ 合 / ☐ 否 | |
| 5 — 生成完了後 polling 停止 | ☐ 合 / ☐ 否 | |

全シナリオが「合」であれば、エディタ自動上書きバグ (B1〜B6) の修正が正常に機能している。
