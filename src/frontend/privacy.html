プライバシーポリシー

改訂日: 2026-05-13

第1条 (収集する情報)

本サービスは以下の情報を収集します。

  • メールアドレスおよび表示名 (アカウント登録時)
  • 会議の音声から生成された文字起こし・議事録・要約・ToDo
  • 利用ログ (アクセス日時・IPアドレス・ブラウザ情報)

第2条 (利用目的)

収集した情報は以下の目的で利用します。

  • 本サービスの提供および機能改善
  • 不正アクセスの検知・防止
  • サービスの品質向上・統計分析

第3条 (第三者提供)

運営者は、法令に基づく場合を除き、ユーザーの情報を第三者に提供しません。

第4条 (外部サービスの利用)

本サービスは以下の外部サービスを利用します。これらのサービスに音声・テキストデータが送信される場合があります。

  • Google Cloud (Cloud Firestore / Cloud Run / Cloud Speech-to-Text) — データの保存・処理基盤
  • Google Gemini API — 議事録・要約・ToDo の AI 生成
  • Groq API (任意) — AI 生成の代替プロバイダー
  • ElevenLabs API (任意) — 高精度音声認識

各サービスのプライバシーポリシーについては、それぞれのサービスプロバイダーのウェブサイトをご確認ください。

第5条 (データの保管場所)

本サービスのデータは Google Cloud の asia-northeast1 (東京) リージョンに保存されます。

第6条 (削除権・エクスポート権)

ユーザーはプロフィール画面から自己のデータのエクスポートおよびアカウントの削除を実行できます (U-2 機能として実装予定)。削除を希望される場合は下記お問い合わせ先までご連絡ください。

第7条 (Cookieの利用)

本サービスはセッション維持のため httpOnly Cookie を使用します。この Cookie はサービスの提供に必要なものであり、トラッキングや広告目的には使用しません。

第8条 (お問い合わせ)

プライバシーに関するお問い合わせは運営者までご連絡ください。
